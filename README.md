# Vara Harsh – Portfolio (React + Vite)

## Run locally
```bash
npm install
npm run dev
```
Open the URL shown in the terminal (usually http://localhost:5173).

## Edit your content
Open `src/data/content.js` and change your email, GitHub, LinkedIn, about text, skills and projects.

## Change colors
Edit the variables at the top of `src/styles.css` (`--bg`, `--accent`, `--accent-2`, ...).

## Build / deploy
```bash
npm run build
```
Upload the `dist` folder to Netlify, Vercel or GitHub Pages.

## Add your photo
Copy your photo into the `public` folder and name it `profile.jpg` (portrait photo, about 800x1000 px works best).
If the file is missing, your initials are shown instead.
